# Changelog

## v0.1.0 - First functional milestone

Local Windows speech and CPU face motion now have a six-choice named-head
workspace, independent colors/default-on pinning, opt-in agent speech and a
calmer browser/native UI. The README adds current six-head GIFs, actual Mark
study excerpts and current controls while preserving the approved hero.

This is an experimental source release, not an installer or accuracy claim.
See [release notes](docs/releases/v0.1.0.md) for setup, evidence, limitations,
recovery and the distinction between shipped capabilities and review studies.
The three earlier prototype releases remain unchanged on GitHub.

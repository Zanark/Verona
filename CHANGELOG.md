# Changelog

## v0.3.0 - Offline voices and living heads

Adds optional28-style offline Kokoro voices, unused-voice session defaults,
unclipped floating zoom and preserved ear/hair tips. All six heads share30
tool-owned idle gestures with coordinated eyes and compound facial motion.
Performance-only sleep is an unchecked creation-time opt-in; normal heads
remain the default. Idle audio is capped at20%; automatic yawn sound has10%
chance and a ten-minute minimum gap. Yawns open around a dark cosmetic cavity.

The refreshed operating skill is installed separately from the source release.
Supplied yawn recordings, optional model packs and private editions are not
distributed. [Release notes](docs/releases/v0.3.0.md) distinguish inherited
qualification, measured CPU savings, retained memory and unaccepted accuracy.
Earlier release tags/assets remain unchanged.

## v0.2.0 - Consistent native speaking heads

Native MPFB and actual Mark share all four presentations and the applicable
Claire controls, including neck/crop, colors, both hairstyles, cursor, blinks,
post-fit MPFB exaggeration and reversible sideways cheekiness. Only the
selected neural identity/adapter loads. Six new model GIFs, updated skill,
chapters and a separate post-M1 journal preserve evidence and prior editions.
See [release notes](docs/releases/v0.2.0.md) for qualification and unresolved
lifecycle/accuracy boundaries. This remains a source release, not an installer.

## v0.1.0 - First functional milestone

Local Windows speech and CPU face motion now have a six-choice named-head
workspace, independent colors/default-on pinning, opt-in agent speech and a
calmer browser/native UI. The README adds current six-head GIFs, actual Mark
study excerpts and current controls while preserving the approved hero.

This is an experimental source release, not an installer or accuracy claim.
See [release notes](docs/releases/v0.1.0.md) for setup, evidence, limitations,
recovery and the distinction between shipped capabilities and review studies.
The three earlier prototype releases remain unchanged on GitHub.

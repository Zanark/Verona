accuracy certification or model bundle.

  conditioning before loading. It is not Male-SharpJawline or relabeled Claire.

## Source distribution and setup

`Verona-v0.2.0-source.zip` contains reviewed tracked source, tests, documentation
and public preview media at this release's exact commit.
`release-manifest.json` inventories every source member and SHA-256;
`SHA256SUMS.txt` covers the ZIP and manifest. Uploaded assets are downloaded
and checked separately. No context stores, credentials, capabilities, profiles,
recordings, local PDF editions, models, environments or native scenes enter
the custom archive.

Prepare the separately pinned assets/dependencies using the
[fresh-clone guide](../prototype-guide.md#fresh-clone-setup) and review
[third-party terms](../../THIRD_PARTY.md). Windows System.Speech, WebGL2 and
Node.js>=22.12/npm are required for native heads. Run
`Setup-VeronaDesktop.cmd` explicitly before `Verona.cmd`; no runtime asset
download or camera/microphone activation is added.

Use the [updated opt-in skill](../../.github/skills/verona/SKILL.md) for a chat's
owned head. Installing instructions does not start speech or activate an
automatic narration hook. Close unused owned heads and reuse a warm selection;
voice-only skips neural motion when latency matters.

## Recovery and publication boundary

Stop the owned speech before retrying; inspect named-session errors rather than
repeatedly creating heads. Restart discards RAM-only clips/settings and replaces
capabilities. Closing a manager tab does not close its process/heads. Exit
manager requests cleanup only of its owned heads; never restart neighbors.

Prior releases/tags are preserved. Recover old source into a separate checkout
with its own prerequisites rather than overwriting an active app. This source
publication is not deployment, an automatic app update, a PDF upload or human
approval. The local post-M1 journal records implementation cutoff `cab23cc`;
this release's final documentation commit is later.

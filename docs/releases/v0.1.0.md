# v0.1.0 - Milestone 1: Local speaking-face workspace

**The first functional milestone is here: type locally, hear a Windows voice,
and watch an independently owned animated face speak.** This is an experimental
0.x source release, not a production-ready assistant, accuracy certification or
bundled installer.

## What this freezes

- One session-led manager for six existing choices: original Claire, procedural
  robot, native MPFB, structural-reference Claire, historical subtle-reference
  Claire and Male-SharpJawline. Experimental/rejected fits remain labelled.
- Independent warm speech engines, audio clocks, five feature colors and
  default-on native topmost per head. The head name/pin stay inside its menu.
- Speech-first browser controls; editable settings separated from immutable
  identity and temporarily unavailable controls; explicit stale/error states.
- Opt-in local agent CLI and a self-contained operating skill. No global
  conversation reader, automatic narration hook or automatic device activation.
- Ten single expression controls, four human presentations plus the robot,
  both current hairstyles, cursor modes, framing and zoom.
- A refreshed README: six new actual-renderer speaking GIFs, two native Mark
  study excerpts, current floating-menu states and the connected manager.
  The approved large captioned hero and unchanged feature/emotion loops remain.

The actual Mark study is **not a seventh manager model**. The proposed stronger
sideways-cheekiness comparison remains **report-only**, not a runtime change.
M1 acceptance does not retroactively accept every experimental likeness.

## Source distribution and setup

`Verona-v0.1.0-source.zip` contains only the reviewed tracked source, tests,
documentation and public gallery at the release's exact source commit.
`release-manifest.json` identifies every source member, its size and SHA-256;
`SHA256SUMS.txt` covers the ZIP and manifest. Downloaded release assets are
verified against those checksums. GitHub's automatic source archives are
additional conveniences, not the checksum contract of this custom ZIP.

There is **no executable installer**, model bundle, voice bundle, Python
environment or Electron installation in the assets. The release manifest
also identifies qualification evidence and what was not rerun or accepted.
Private context, raw capture frames, speech recordings and credentials are
excluded. Review [third-party terms](../../THIRD_PARTY.md) before acquiring
the separately pinned assets; rendered previews are not model redistribution.

Requires Windows (qualified here on Python3.13), an installed English desktop
System.Speech voice, a WebGL2-capable browser, and Node.js>=22.12/npm for native
Electron heads. Begin with [fresh-clone setup](../prototype-guide.md#fresh-clone-setup).
Explicit Python/model preparation and `Setup-VeronaDesktop.cmd` are required;
then start `Verona.cmd`. Runtime is local/CPU and does not download assets.
Reference/MPFB choices additionally require the local study assets described
in the guide; a source ZIP does not make an unprepared machine equivalent to
the qualified checkout. No clean-machine installation acceptance is claimed.

For another opted-in Agency session, use the
[Verona skill and full-path handoff](../../.github/skills/verona/SKILL.md).
Inventory existing heads first; choose clearly distinct solid hue families,
not another light shade of a neighbor. All RGB choices remain available.

## Evidence and limits

The gallery was generated from runtime source
`d7897633ea0994817a2c3008e60a9fe2ab90df6c`. This release changes documentation,
media and tracking only; the manifest verifies the same runtime files.
Six isolated CPU servers/hidden sandboxed renderers used one synthetic Hazel
greeting, bounded sequential work and private caches/profiles. The nine new
GIFs contain281encoded frames; every expected sample matches its decoded
timeline. Contact-sheet/reader images were inspected, not every frame.

The release gate reruns76CPU regressions. Native/browser qualification from
vr-50 is retained evidence for unchanged runtime: actual six-model speaking
sessions, cancellation/cleanup, manager fixtures, encoded WebGL/menu/layout
checks and independent topmost behavior. It is **not a fresh rerun** of every
native interaction. [Media provenance](../media/README.md) distinguishes fresh
capture, reused fixtures and older unchanged gallery loops.

Generation is precomputed, not streaming: each warm head costs CPU/RAM and a
Chromium renderer. Close unused heads, reuse the selected warm head and choose
voice-only when response latency matters more than lip motion. An eight-head
safety cap is not an eight-head performance guarantee.

Full SDK contact/smoothing and independent teeth/tongue/eye joints are omitted.
Phonetic/human accuracy, independent listening, photorealism and all identity
acceptance remain open. No recording import or conversational assistant ships.
GIFs are silent sampled previews, not native playback-rate measurements.

## Failure, restart and recovery

Wait for ready; inspect explicit setup/generation errors rather than repeatedly
creating heads. Use **Stop this speech** before retrying a failed/cancelled job.
If a head window is closed, inspect its named status and explicitly recreate
only that session when requested; there is no promise that an idle chat
automatically observes a window close. Closing the manager tab leaves its
process/heads alive; reopen its current private capability URL. Exit manager
or Ctrl+C requests cleanup of only its owned heads.

Speech, clips, drafts and customization are RAM-only. A restart loses them and
creates new capabilities; old URLs/descriptors must not be reused as live
authority. WebGL loss requires reloading the owned player, not restarting a
neighbor. Topmost cannot override secure desktops or every fullscreen app.
See the [guide](../prototype-guide.md) for precise ownership/cancellation rules.

Existing prototype.1/.2/.3 releases and tags remain immutable history.
Recover an earlier source version into a separate checkout with its documented
prerequisites; do not overwrite a running user's code, profiles or assets.
Publication of this source release is **not deployment**, an automatic update,
an active-window restart or a rendered engineering-book edition.

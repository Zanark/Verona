# v0.3.1 - Recorded local idle effects

Supplied local female/male sneeze recordings replace the synthesized sneeze.
Both yawn and sneeze now follow selected voice metadata through the same
bounded loader. This is a Windows-local source patch over
[v0.3.0](v0.3.0.md), not an installer or an audio/model bundle.

## Behavior and setup

The offline helper `scripts/prepare-idle-yawns.cjs` retains its yawn default
and adds explicit `--kind=sneeze`. Prepared clips are monoPCM16/24kHz, with
silence trimming,25ms fades and a2.7s sneeze limit; yawns retain4.2s.
Original recordings remain unchanged. Only the current kind/style buffer is
retained. Four exact authenticated routes validate the respective bounds.
There is no synthesized, downloaded or cloud fallback for missing effects.

**No supplied recordings are distributed.** Use authorized local files and
the [preparation guide](../prototype-guide.md#autonomous-idle-life). Keep
idle sound muted until both effect kinds are prepared on a fresh checkout.
Local trim/play permission does not establish redistribution rights.

The20%hard gain cap, independent mute, speech/input/sleep cancellation,
normal default and creation-only performance opt-in remain unchanged.
Visual yawn weight3 and automatic yawn10%audio chance/600s minimum also remain.

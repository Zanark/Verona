# v0.3.0 - Offline voices and living heads

**Distinct local voices and thirty autonomous idle gestures across all six heads.**
This is an experimental Windows-local CPU source release, not an installer,
prepared environment, recording bundle or accuracy certification.

## Changes since v0.2.0

- Optional28-style English Kokoro INT8 voices complement installed Windows
  voices. New heads reserve an unused installed voice; manual collisions are
  visibly marked. One lazy local model per requesting head serves its styles,
  not28 models or a global broker. Runtime never downloads weights.
- Above100%zoom, the native viewport grows within monitor bounds. A separate
  skin-only jaw crop preserves ears and complete selected hair tips. Screen
  limits still constrain maximum visible enlargement.
- All six heads/four presentations share30 tool-owned gestures, including five
  eye actions and ten composites overlapping at least three facial fields.
  Look-around moves actual irises in either cursor mode. Speech and direct
  interaction preempt idle behavior; chats schedule nothing.
- Normal heads remain the default. **Performance-only head** is unchecked at
  creation and immutable afterward. Opted-in silent heads use10%opacity and
  stop idle redraws, cursor tracking, blinking and gestures; speech restores
  100%. Independent normal opacity remains adjustable from the floating menu.
- Yawns separate the lips around an oval dark cosmetic cavity. Prepared local
  effects follow selected voice metadata; sneeze remains locally synthesized.
  Idle audio defaults to20%, also its hard maximum, independent of speech.
- Automatic visual yawns have10%chance of sound and at least ten minutes
  between successful sound starts. Most remain silent without loading audio.
  Visual yawn weighting stays3x each other eligible action. Explicit previews
  bypass rarity, not mute/cap, and advance the automatic sound cooldown.
- Updated operating skill, README, guides, chapters and living development
  journal describe current behavior without rewriting frozen editions/media.

## Qualification and limits

The final vr-76 qualification passes720 real-native action/view cases across
six heads and four presentations, plus both immutable creation policies.
Actual local buffers, David/Hazel effect selection, gain/range cap,
mute/cancellation/output errors and speech preemption are checked. Seven
focused Node runner cases, eleven Python server/audio cases and nine existing
book checks pass. These are inherited runtime results, not new release tests.
Actual Claire Surface/FaceMesh frames and a compact six-head sheet were
reviewed; there is no independent listening or complete-animation acceptance.

Earlier vr-73 counterbalanced16-second windows measured moving-cursor Electron
one-core CPU28.856%normally versus0.368%in opted-in sleep. Working set was
755.68/754.61MiB: essentially unchanged. These scoped measurements in
[chapter07](../chapters/07-hazel-claire-and-performance.md#measured-idle-performance-mode-vr-73)
are not whole-machine savings or a new benchmark of this release. Speech models
stay warm. Optional neural voices add memory and cold-start CPU costs.

The retained warm-worker voice-metadata failure was corrected in both Windows
inventories. Earlier native shutdown/startup delays remain unresolved under
vr-64; no timeout extension or hidden success fallback is introduced.
Contact correction, independent teeth/tongue/eye joints, phonetic accuracy,
human identity/likeness, instant replies and clean-machine acceptance remain
unclaimed. The dark yawn interior is cosmetic, not a physical oral rig.

## Setup and private audio boundary

Use the [fresh-clone guide](../prototype-guide.md#fresh-clone-setup), explicitly
install the pinned desktop dependencies, then run `Verona.cmd`.
[Optional voice setup](../prototype-guide.md#optional-28-voice-offline-pack)
is separate. Windows voices work without Kokoro. Its pitch/emphasis controls
are unavailable; speed/bass/treble are supported. Review
[third-party terms](../../THIRD_PARTY.md) including phonemizer/eSpeak licensing.

**No supplied yawn recordings are distributed.** On a fresh checkout, mute idle
sound until authorized local clips are prepared with the guide's explicit
offline Electron helper. Idle motion itself works without the files. Missing
or invalid effects produce a visible error, not a download or synthesized
yawn fallback. Local permission to trim/play is not redistribution permission.
No microphone, camera, cloud speech or automatic setup is activated.

## Source release and recovery

`Verona-v0.3.0-source.zip` contains reviewed tracked source, tests, documentation
and previously public preview media at this release's exact commit.
`release-manifest.json` inventories every source member/hash; `SHA256SUMS.txt`
covers the archive and manifest. Uploads are downloaded and checked separately.
Context stores, credentials, capabilities, profiles, recordings, local effects,
models/native scenes, environments, dependencies and PDF editions are excluded.

The [operating skill](../../.github/skills/verona/SKILL.md) is self-contained
instructions, not a runtime installer. Updating installed copies does not make
already-open agents reload them, start speech or transfer another head's ownership.
Reuse an owned ready head and its recorded name; inspect failure before retrying.
Do not Exit a shared manager or restart neighbors to apply documentation.

Earlier tags/releases/assets and frozen journal editions remain unchanged.
Recover old source into a separate prepared checkout, never over a running
app. Publication is not deployment or an automatic live update. The runtime
baseline for this documentation milestone is commit `f2c7c83`.
